# تفعيل مساعد الدردشة الذكي (Claude) على موقع HUR-UAV-01

مربع الدردشة في الموقع الآن مربوط فعلياً بواجهة Claude من Anthropic عبر ملف PHP خادمي (`api/chat.php`) — الزائر يكتب سؤاله، ويرد عليه الذكاء الاصطناعي مباشرة بمعلومات دقيقة عن HUR-UAV-01 وفلاي زون، ويوجّه الاستفسارات الجادة (الأسعار، الطلبات، التخصيص) إلى واتساب.

## خطوات التفعيل (٥ دقائق)

**١. احصل على مفتاح API من Anthropic**
اذهب إلى [console.anthropic.com](https://console.anthropic.com) → أنشئ حساباً (أو سجّل دخول) → **Settings → API Keys → Create Key**. انسخ المفتاح (يبدأ بـ `sk-ant-...`).
ملاحظة: يحتاج الحساب رصيداً/فوترة مفعّلة (Billing) حتى يعمل المفتاح — كل رسالة دردشة تُحتسب كاستخدام API حقيقي بتكلفة صغيرة.

**٢. أنشئ ملف `config.php`**
في File Manager، داخل مجلد `api/` (بجانب `config.sample.php`):
- انسخ `config.sample.php` والصقه باسم جديد: `config.php`
- افتحه بـ **Edit** واستبدل `YOUR_ANTHROPIC_API_KEY_HERE` بمفتاحك الحقيقي
- احفظ

**٣. جرّب الموقع**
افتح الموقع، اضغط على أيقونة المحادثة الزرقاء (أسفل يسار الشاشة)، واسأل سؤالاً مثل "ما هو زمن التحليق؟" — يجب أن يرد المساعد برقم دقيق (17 دقيقة) خلال ثوانٍ.

## ما الذي يعرفه المساعد؟

كل معلوماته مأخوذة حصراً من النشرة التقنية الرسمية لـ HUR-UAV-01 (نفس البيانات المستخدمة في تصميم الموقع): المواصفات، التقنيات، الاستخدامات، معلومات التواصل. تم توجيهه صراحة بعدم اختلاق أي رقم أو ميزة غير موجودة، وبتحويل أي استفسار عن السعر أو طلب مخصص مباشرة إلى واتساب (00905366976222) بدل تخمين إجابة.

## الحماية من إساءة الاستخدام

الملف يتضمن حداً أقصى تلقائياً: **15 رسالة لكل زائر (حسب IP) كل 10 دقائق** — يمنع أي استغلال آلي أو إساءة تُحمّلك تكاليف API غير متوقعة. يمكن تعديل هذين الرقمين من داخل `config.php`:
```php
define('RATE_LIMIT_MAX_REQUESTS', 15);
define('RATE_LIMIT_WINDOW_SECONDS', 600);
```

## تغيير النموذج (اختياري)

الإعداد الحالي يستخدم `claude-opus-5` (الأعلى جودة). لخفض التكلفة إن ارتفع عدد الزوار كثيراً، يمكن تغيير السطر التالي في `config.php` إلى نموذج أرخص وأسرع:
```php
define('ANTHROPIC_MODEL', 'claude-haiku-4-5');
```

## إذا لم يرد المساعد

- تأكد أن `config.php` موجود فعلاً وبه المفتاح الصحيح (وليس النص الافتراضي).
- تأكد أن رصيد حساب Anthropic مفعّل (Billing) في console.anthropic.com.
- افتح Developer Tools في المتصفح (F12) → تبويب Network → أرسل رسالة → افحص استجابة `api/chat.php` لمعرفة رسالة الخطأ الدقيقة.
- في حال الفشل، يعرض المساعد تلقائياً رسالة احتياطية تطلب من الزائر التواصل عبر واتساب — فلا تُفقد أي فرصة عميل حتى أثناء أي عطل مؤقت.
