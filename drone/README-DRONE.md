# موقع FLYZONE — HUR-UAV-01

موقع تسويقي بثلاث لغات (عربي، تركي، إنجليزي) لمنظومة الدرون **HUR-UAV-01** من شركة **FLYZONE** (إسطنبول)، مبني كجزء مستقل ضمن هذا المستودع تحت مجلد `drone/`، دون أي تعديل على الموقع الحالي في جذر المستودع.

## الملفات
- `ar.html` / `tr.html` / `en.html` — نسخ الموقع الثلاث (بنية وهوية بصرية متطابقة).
- `index.html` — صفحة اختيار اللغة (تحاول أيضاً اكتشاف لغة المتصفح تلقائياً).
- `css/styles.css`, `js/main.js` — التنسيق والمنطق المشترك بين الصفحات الثلاث.
- `assets/img/` — الصور والشعار وأيقونات المواصفات، مستخرجة من نشرة FLYZONE التقنية الرسمية (PDF المرفق).

## البيانات المستخدمة
كل المحتوى (اسم الشركة، اسم المنتج، المواصفات الرقمية، النص التعريفي، العنوان، رقم واتساب/الهاتف +90 536 697 62 22، البريد الإلكتروني) مأخوذ مباشرة من نشرة FLYZONE الرسمية لمنظومة HUR-UAV-01. لم تُختلق أي مواصفات أو ادعاءات.

## قبل ربط وكيل الذكاء الاصطناعي
عند تجهيز الوكيل، افتح `js/main.js` وعدّل داخل `SITE_CONFIG`:
```js
LEAD_WEBHOOK_URL: "",   // رابط الـ webhook لاستقبال بيانات نموذج التواصل
CHAT_WEBHOOK_URL: "",   // رابط الـ webhook لاستقبال رسائل مربع المحادثة (اختياري، وإلا يُستخدم نفس الرابط أعلاه)
```
حتى يتم تفعيلهما، يستمر الموقع بالعمل عبر واتساب كخطة بديلة مضمونة (لا تُفقد أي رسالة أو طلب).

## النشر
المستودع يحتوي على GitHub Actions لنشر كامل المحتوى على GitHub Pages تلقائياً عند الدفع لفرع `main`. بعد الدمج، سيكون الموقع متاحاً على:
`https://<username>.github.io/<repo>/drone/` (والصفحة الرئيسية الحالية تبقى كما هي على المسار الجذري).

## ملاحظة
جميع النصوص التسويقية كُتبت بأسلوب مهني يعتمد على المعلومات الحقيقية من النشرة. يُفضّل مراجعة فريق FLYZONE للنسخ الثلاث قبل الإطلاق الرسمي للتأكد من دقة الترجمة التقنية والقانونية (خاصة العنوان وبيانات الشركة).
